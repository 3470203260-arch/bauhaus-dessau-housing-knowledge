# 知识标准

本版知识元52条，一条最小命题对应一条关系，不相加。节点69个，包含人物、建筑或聚落、研究条目、概念和属性值，不声称为69个历史实体。9项中文来源按独立作品计数；同篇上下网页不重复计算。

sources：id author title category url locator accessed reference access_scope additional_url。
entities：id label type aliases。
knowledge_units：id subject predicate object statement source_ids locator epistemic_status review_status human_reviewer human_review_date。
relations：id subject_id predicate object_id knowledge_id source_ids epistemic_status。

来源明示44条，指所读材料明确表达的命题，可能是作者观点或项目记述，不能全部称作一手历史事实。本文分析8条，标识比较和解释，不当作已证实因果。人工核验0，不将AI对照计入。后续由实际审核人填写审核表。

辅助展示记录：case_comparisons为3条案例阅读组织，presentation_profile为规则档案，presentation_task为当前任务，presentation_review为分维度核验。均不增加历史来源、节点、知识元或关系统计。课堂M01只为方法参考。

实际type分类及节点数：{"文献": 8, "概念或属性值": 55, "建筑或聚落": 4, "人物或人物组合": 2}。未另建机构类实体，建筑部门集体项目当前为属性值；文献节点数不等于来源表记录数。

id为表内唯一键；source_ids为分号分隔的来源表外键；locator记录实际印刷页或网页节段，不互相冒充；epistemic_status只取来源明示或本文分析；human_reviewer和human_review_date仅据真实人工审核填写。relations的subject_id和object_id回指实体表，knowledge_id回指最小命题，谓词、来源和证据身份应与对应命题一致。关系的五组用途为解释性归纳，不是已存在的新字段。

argument_checks为8条辅助论证核对记录，回指K045—K052。记录证据作用、来源独立性、推论边界、修正条件和真实审核状态，不增加历史成果统计。M02仅为方法参考，见workflow_adaptation.md。


## 粒度 著录与核验

一条知识元只表达一个可回查关系；来源明确说居住与工作室并置，可记为“包含使用”，但活动是否无冲突须另作分析，不并入事实。引用只释义必要内容，不复制原文长段。同一主体/谓词/客体不得重复入库；同名人物按别名归并，原文题名保留原译名。不同建筑、原建和重建不得仅凭名称近似合并。

四种实体type及数量见上文。type为“文献”的8节点表示S01—S08相关研究条目，不是8份原始档案，也不等于来源表9项作品；S09用于项目出处，未另立文献节点。“概念或属性值”含组织属性、功能和解释对象，不声称都是历史上的独立实体。当前无师承/直接影响关系；不能为迎合示例而添加。

正式字段规范：编号不可为空且表内唯一；source_ids按分号存已有S编号；locator按实际载体写印刷页或网页节段；aliases按分号存同一对象的不同名称，不将近义概念当别名；review_status记AI处理状态；human_reviewer/human_review_date仅凭真实人工记录填写；属性值没有独立身份时不补造年代或机构档案。来源的author/title/category/url/reference/access_scope分别记录责任者、题名、载体、读取入口、完整书目与实际读取范围；additional_url为同作品补充入口或书目复核，不能重复计作品或独立证据。accessed为登记访问日，不等于期刊出版日。

人工抽检逐条核对命题、责任、范围和推论身份，记录“支持/部分支持/不支持/无法判定”，未读留待本人核验。遇不支持先保留原记录与问题，修改或剔除后同步CSV/JSON/SQLite及网页，重跑结构检查；不能只改统计数。匿名公开表不填写真实姓名，实际身份与已填工作表保留本地。

## 来源层级

9项均为本专题所研究1920年代住宅的二手研究或介绍；未纳入原始德文宣言、项目档案、同期施工图或住户记录。出版社/馆方原版PDF是所读版本的直接载体，不会因此变成德绍项目的一手档案。若研究当代作者观点，其署名文章可作为该观点的直接证据，须说明研究对象变化。source_roles.csv/json逐项记录层级、研究用途、载体和读取范围；不增加来源数。
