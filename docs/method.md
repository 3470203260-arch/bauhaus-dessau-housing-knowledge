# 问题与方法

研究问题：德绍住宅把哪些生活关系纳入统一设计，又给使用者留下哪些需要调整的空间？比较大师住宅工作/居住、托尔滕排屋室内/园地劳动、外廊住宅单户/公共通道。生活边界是活动和使用责任的交接，不等于简单的几何分隔。

流程：问题限定→中文来源检索→元数据及实际读取范围检查→最小命题抽取→名称归一→来源明示与分析区分→冲突保存→CSV JSON SQLite导出→结构验证→图谱及论文使用→本人实质核验。

AI辅助工具为Codex、联网检索、Python、python-docx、Pillow、SQLite及GitHub。底层模型具体版本未核实。AI完成整理、对照、代码及草稿，本人尚需实际阅读审辨，审核人和日期未代填。未开展访谈、测绘或性能测试。

本版全部采用中文来源；6篇期刊论文、1部专著、1篇馆刊、1项项目媒体资料。不同类型按其证据能力使用。S07只读作者下篇节选；S03只读出版社试读第五章。没有取得原件的不声称原件级核验。不分发原文全文及照片。
