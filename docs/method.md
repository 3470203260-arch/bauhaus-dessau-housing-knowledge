# 建库流程与人机分工

专题围绕德绍住宅的生活边界与空间协同，比较工作/居住、室内/园地及单户/公共通道；不扩展为无限的包豪斯风格资料合集。以下仅记录已发生的整理与检查，人工实质抽检尚待提交者完成。

| 环节 | 实际输入与处理 | 已有输出及责任 |
| --- | --- | --- |
| 问题限定与筛选 | 中文可读、责任者可辨、与住宅活动组织相关；排除纯配色、品牌及几何风格展示；无完整候选排除日志，不虚报淘汰数 | 9项作品及边界，AI辅助整理，提交者待审辨 |
| 采集与预处理 | 逐项核作者、题名、期次与实际读取范围；上下篇并为一作品；PDF核印刷页，网页以节段定位；不以下载成功证明内容正确 | sources.csv/json、source_roles.csv/json，AI对照；不公开全文或照片 |
| 最小命题抽取 | 从已读范围分别抽取作者观点、项目记述与本文解释，一项关系一条，不补住户成效 | K001—K052；44来源明示、8分析；AI抽取，人工待审 |
| 消歧与构边 | 托尔滕/特尔滕及迈耶/梅耶按对象统一，题名保留；集体实施与领导分开；只以共现不能建影响关系 | entities及relations；36谓词定义见relation_dictionary |
| 去噪与纠偏 | 已记录Q01—Q06：年代概括、图注责任、原刊分页、节选、证据层级、使用资料缺口；处理是AI对照，不冒称人工抽检 | issues.csv保留问题、依据、当前处理与未解决缺口 |
| 入库与迭代 | 中文资料重建替换旧外文论述，后续展示、论证与词典均不增加历史规模；同一次更新同步四种表示 | CSV/JSON/SQLite/index.html；Python与SQLite导出，校验后发布 |
| 复核与有效性检查 | 核对编号、外键、关系与命题、CSV/JSON/SQLite/网页一致、来源/谓词词典和3个SQL问题 | tools/validate.py及query_evaluation.md，属结构/可追溯检查 |
| 人工抽检与回写 | 提交者实际读原文并判断；记录抽样依据、数量、发现、处理和实际日期，必要时修文再入库 | 目前0；本地07/08帮助填写，不代签、不公开私人已填记录 |
